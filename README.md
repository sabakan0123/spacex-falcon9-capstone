# Falcon 9 landing analysis

This is an independent reproduction using the IBM course datasets, not the student's previous notebook submissions. Data in `dataset_part_2.csv` has 90 preselected launches from 2010–2020 and the SQL source has 101 rows; results should not be mixed. The preprocessed payload mass includes imputation performed in the course data. The 32-slide [Data Science Capstone Project Report.pdf](Data%20Science%20Capstone%20Project%20Report.pdf) summarizes the methods and results.

Install dependencies with `python -m pip install -r requirements.txt`. Open the executed `spacex_capstone.ipynb` to explore the analysis, or run `python analyze.py` to download the course data, run SQL queries and train the classifiers. The model uses an 80/20 stratified split (seed 42), four-fold training cross-validation, and a separate holdout set. One-hot encoding, imputation, and scaling are fit inside the pipeline. `model_results.json` contains the full metrics. No hyperparameter search was performed.

Run `python data_collection.py` to demonstrate API-response collection and Wikipedia scraping. The live API timed out during our run, so its sample came from the IBM course's static API-response snapshot. The scrape uses a fixed 2021 Wikipedia revision. These separate samples were not used to fit the models.

Run `python visual_analytics.py` to generate `launch_sites_map.html` and `launch_proximity.html` and start the Dash app at http://127.0.0.1:8050. Stop it with Ctrl+C. The map contains individual launch records and an approximate coastal reference point. The indicated 0.94 km is a straight-line distance to that selected point, not a nearest-shore measurement. These are course-era historical data, not current SpaceX performance.

The notebook, analysis scripts, map and dashboard are an independent reconstruction. They do not claim to be the original course lab notebooks.
